# Editorial Policy

Awesome KyoAni is a curated recommendation list, not an exhaustive directory. Inclusion means a resource is useful enough to recommend to a defined audience and adds value that the existing list does not already provide.

## Baseline Requirements

Every listed resource must be:

1. **Directly relevant**: Kyoto Animation is central to the resource, not a passing reference, tag, screenshot, or optional theme.
2. **Useful**: It serves a recognizable need for viewers, researchers, creators, animation professionals, preservationists, or the community.
3. **Understandable**: A newcomer can determine what it provides and how to use or access it.
4. **Distinct**: It contributes meaningful value beyond existing entries.
5. **Recommendable**: Its case does not depend on popularity, ratings, stars, follower counts, or search ranking.
6. **Appropriate to link**: It does not primarily redistribute unauthorized animation, music, books, scans, production materials, or other copyrighted works.

Resources do not need recent activity, a minimum audience, or a popularity threshold. Finished, inactive, archived, specialist, and non-English resources remain eligible when they are useful and accessible.

## Acceptance Paths

A resource meeting every baseline requirement should also fit at least one path:

- **Authoritative source**: A first-party or otherwise authoritative website, work page, publication, catalog, store, channel, archive, or event resource.
- **Established community resource**: A demonstrably useful community, database, archive, event, reference, or tool with a substantial Kyoto Animation focus.
- **Exceptional niche resource**: Specialized research, preservation, technical, historical, educational, or community work that would be difficult to replace.

These paths are not popularity tiers. A small specialist archive may be more valuable than a widely shared but shallow page.

## Scope and Placement

Good fits include official resources; structured catalogs; production research; substantive creator interviews; books and bibliographies; music and audio references; pilgrimage maps and location research; established communities; reusable fan projects; and scholarly or long-form criticism.

Usually exclude generic anime databases without meaningful Kyoto Animation-specific value, personal bookmark collections, isolated fan works, minimally documented demos, general software with a Kyoto Animation theme, advertising, affiliate links, piracy, unauthorized downloads, scans, rips, or copyrighted-material dumps.

Use thematic sections for studio-wide or genuinely cross-work resources. Place a resource dedicated primarily to one production under that title in **Works**. Never duplicate the same resource in both locations.

Create a work subsection only when at least one strong dedicated resource is ready. Create any other section only for a meaningful cluster of qualifying resources, with a one-sentence scope description and a matching Contents entry. Remove a section when it no longer contains a qualifying resource.

## Names, Languages, and Access

Use the canonical resource name unless contextual qualification is needed to keep catalog names unique and understandable. The catalog and descriptions are in English; resources in any language are welcome. State the language when it materially affects use.

Disclose material access limits such as payment, institutional access, regional availability, account requirements, proprietary file formats, or unreliable automated access. An access limit is not automatically disqualifying when the resource remains useful to its intended audience.

## Preservation and Historical Resources

Age, inactivity, or archive status alone is not a reason to remove a resource. Keep a finished or inactive resource in the main list while it remains useful for its intended purpose.

When a resource becomes broken, obsolete, or superseded:

- Update its canonical URL when the same resource moved.
- Replace it with a successor only when the successor is clearly the better recommendation.
- Move it to `historical.md` only when it is no longer a current recommendation but retains irreplaceable source, research, technical, or preservation value.
- Remove it without a historical entry when it is inaccurate, insubstantial, duplicative, or lacks continuing reference value. Git history remains the record of that removal.

Do not create an empty historical catalog. Add `historical.md` with the first resource that actually qualifies for it.

## Review and Audit

Automated checks enforce Markdown structure, HTTPS, unique names and URLs, ordering, descriptions, Contents anchors, and nonempty sections. They cannot establish relevance, factual accuracy, legal status, accessibility to a real user, or semantic duplication.

For every addition and periodic catalog audit, a reviewer should:

- Open the resource and verify that the description matches what is available.
- Confirm the Kyoto Animation connection and intended users.
- Check the canonical URL, language, source type, and access limits.
- Compare it with nearby entries for overlap and narrowest placement.
- Consider publisher stability and preservation risk.
- Record non-obvious exclusions or retention decisions in the pull request discussion.

The main list should improve through editorial judgment, not grow toward a completeness quota.
