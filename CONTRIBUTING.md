# Contributing

Thank you for helping make Awesome KyoAni more useful. This is a curated list, not a directory of every Kyoto Animation-related link. Read the [editorial policy](EDITORIAL.md) before proposing a resource or entry update.

## Ways to Contribute

- Use the resource-suggestion issue form when you want maintainers to evaluate a resource before you prepare a pull request.
- Use the entry-update issue form for a broken, moved, inaccessible, duplicated, outdated, or superseded entry.
- Open a pull request when you are ready to make a focused catalog change.

Search the README, open and closed issues, and open and recently closed pull requests before submitting. One standalone resource per pull request is preferred. A coherent maintainer-led audit may group related corrections.

## What to Provide

Every new-resource proposal must identify:

1. The resource's canonical name and HTTPS URL.
2. Its direct and verifiable Kyoto Animation relevance.
3. The intended users and the need it serves.
4. The resource and interface languages.
5. Its source type: authoritative, community, research, catalog, publication, tool, archive, or another clearly described type.
6. The distinct value it adds beyond existing entries.
7. Any login, payment, region, software, or other access limitations.
8. Your affiliation with the resource, or “None.”
9. Confirmation that it does not primarily redistribute unauthorized copyrighted material.
10. Confirmation that your submitted catalog text may be distributed under this repository's CC0 license.

Recent activity, stars, followers, rankings, and popularity are not required. Do not use them as the main reason a resource belongs.

## Entry Format

Use the canonical resource name and an HTTPS URL. Write a concise, factual English description that starts with an uppercase character and ends with a period.

```markdown
- [Resource Name](https://example.com/) - What it provides and why it is useful.
```

Keep entries alphabetized within their section. A resource dedicated primarily to one production belongs under that title in **Works**. Do not duplicate it in a thematic section. Add a work subsection only when a strong dedicated resource is ready to include.

## Before Opening a Pull Request

- Read or inspect the resource rather than relying on a search snippet or popularity signal.
- Confirm that Kyoto Animation is central to the resource.
- Use the canonical primary-source URL where possible.
- Add the entry to the narrowest appropriate existing section.
- Check the name, URL, description, language note, placement, and alphabetical order.
- Run the validation commands documented in the pull request template.
- Keep unrelated catalog changes in separate pull requests.

Maintainers may edit descriptions, move entries, request stronger evidence, or decline a submission that does not improve the curated list.
